# Authoritative Content Sources

This directory holds the original, unaltered source documents behind the
site's approved copy. They are the record of truth — everything in
`knowledge/01_company.md` and `knowledge/02_service_pillars.md`, and every
pillar's content in `src/content/pillar-pages.ts`, was extracted from these
two files.

## Documents

- **`Pixelocracy_Master_Plan_Content.docx`** — the site-wide content source.
  Company mission/vision, "Who We Work With," and the full messaging house
  per pillar (overview, what's included, value propositions, client pains,
  proof points, key differentiator).
- **`Pixelocracy_Service_Pillars_Website_Content.docx`** — the authoritative
  source for all five service pillar pages' hero/challenge/how-we-help copy
  and structure.

## Rule going forward

Future pillar (and any other content) work must reference these repository
copies, not a personal Downloads folder or any other local copy. If a
document is ever revised, replace the file here under the same canonical
filename so the history stays in Git.
